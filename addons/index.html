طريقة التثبيت في Firefox

💻 Firefox على الكمبيوتر
  1. عند توفر النسخة الموقّعة من Mozilla اضغط رابط التثبيت من هذه المكتبة ووافق على الأذونات.
  2. إذا نُزّل ملف XPI موقّع بدل فتح نافذة التثبيت، افتح Firefox ← الإضافات والسمات (about:addons) ← ⚙️ ← تثبيت إضافة من ملف.
  3. للنسخة غير الموقّعة الحالية: للاختبار التطويري فقط، فك ضغط ملف XPI إلى مجلد، وافتح about:debugging ← This Firefox ← Load Temporary Add-on ← اختر manifest.json. هذا تشغيل مؤقت وينتهي بإغلاق Firefox.
📱 Firefox على Android
  1. بعد توقيع الإضافة، نزّل ملف XPI على الهاتف.
  2. افتح إعدادات Firefox ← حول Firefox، واضغط شعار Firefox خمس مرات سريعًا لعرض خيارات المطور المخفية.
  3. ارجع إلى الإعدادات ← Install Extension from File (تثبيت إضافة من ملف) ← اختر ملف XPI الموقّع ← إضافة.

قد تختلف أسماء القوائم حسب لغة Firefox وإصداره؛ التوقيع والتوافق مع Firefox Android شرطان أساسيان.

التحديثات: سنعرض هنا رابط النسخة الموقّعة بعد اعتمادها. لا يستطيع تطبيق الويب تثبيت إضافة Firefox دون موافقة المستخدم. ولن تَستخدم هذه المكتبة مفتاح Gemini مركزيًا دون اختيار ذلك صراحةً.
