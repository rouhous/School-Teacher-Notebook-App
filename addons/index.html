توقيع Mozilla · 2.8.21

📚 تحضير دروس نور

إضافة تحضير الدروس في منصة نور مع مكتبة المحتوى وإمكانات التحضير الذكي. تعمل داخل Firefox عند فتح صفحات نور المعتمدة.

الإصدار: 2.8.21

تثبيت الإضافة في Firefox تنزيل ملف XPI

بعد التثبيت افتح منصة نور لتظهر أدوات التحضير. على الهاتف يُستخدم خيار «تثبيت إضافة من ملف» الموضح أدناه.

📝 المهام الإلكترونية

إدراج الأنشطة والأسئلة في منصة نور بحسب الصف والوحدة والدرس؛ ستتاح حزمة مستقلة بعد التحقق من عملها.

📊 نقل الدرجات إلى نور

تعبئة درجات دفتر المعلم داخل نور بعد مطابقة الأسماء ومراجعة البيانات، مع إبقاء الحفظ النهائي بيد المعلم.

طريقة التثبيت

💻 Firefox على الكمبيوتر
  1. اضغط «تثبيت الإضافة في Firefox»، ثم وافق على طلب التثبيت والصلاحيات إن ظهر.
  2. إذا قام المتصفح بتنزيل الملف بدل تثبيته، افتح «الإضافات والسمات» (about:addons) ← ⚙️ ← «تثبيت إضافة من ملف» وحدد ملف XPI.
  3. بعد الإضافة افتح صفحة الدرس في نور. يتطلب هذا الإصدار Firefox 140 أو أحدث.
📱 Firefox على Android
  1. اضغط «تنزيل ملف XPI» لحفظ الإضافة الموقّعة على الهاتف.
  2. في Firefox افتح «الإعدادات» ← «حول Firefox»، واضغط شعار Firefox خمس مرات سريعًا.
  3. عد إلى «الإعدادات» ← Install Extension from File ← حدد ملف XPI ← «إضافة».
  4. يتطلب هذا الإصدار Firefox Android 142 أو أحدث.

🔐 Gemini والتحضير الذكي

يستخدم الإصدار 2.8.21 مفتاح Gemini الشخصي الذي يُدخله المعلم عند تفعيل التحضير، ولا ينشئ المفتاح تلقائيًا من حساب Google بعد. عند توليد التحضير يُمرَّر المفتاح إلى خدمة Supabase الخاصة بالتحضير؛ لا يعني تسجيل الدخول إلى دفتر المعلم تفويضًا تلقائيًا لـ Gemini. مسار تفويض Google الشخصي ما زال مؤجلًا للاختبار.

التثبيت يتم بموافقة المعلم؛ لا يستطيع دفتر المعلم تثبيت إضافة Firefox تلقائيًا، ولا يستطيع موقع الويب التأكد من وجود الإضافة ما لم تتضمن الإضافة آلية تواصل مخصصة.
