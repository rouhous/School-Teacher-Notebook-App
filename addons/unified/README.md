# أدوات نور الموحدة — Firefox (2.8.22، مرشح تطوير)

يرتبط هذا المرشح بإضافة تحضير نور الموقّعة 2.8.21 عن طريق **نفس معرف Mozilla**. الملف البرمجي مرفق ضمن [حزمة المصدر](./Noor-Unified-v2.8.22-source.zip) ويحتوي على الإضافة كاملة عدا التوقيع، مع تعليمات تفصيلية.

**الحالة الحالية:** غير موقّع. لا نضعه بدل نسخة 2.8.21 المتاحة للمعلمين قبل توقيع Mozilla واختبار نور.

- Gemini: تخزين مفتاح مستقل محليًا لكل حساب معلم مرتبط بالدفتر؛ لا يُستخدم مفتاح موحد، ولا يتم إنشاء مشروع Google تلقائيًا عبر OAuth في هذا الإصدار.
- الدرجات: استقبال صيغة التصدير الأصلية من الدفتر ومطابقة الطلاب، ومعاينة وتعبئة بعد موافقة المعلم **دون حفظ نهائي**.
- بنك الأنشطة/الاختبارات: استيراد JSON واختيار الوحدة والدرس وتعبئة مبدئية للعنوان والتعليمات، أما إدراج الأسئلة كاملة وحفظها في نور فيحتاج اختبارًا على صفحات نور الحقيقية.
- التحديث التلقائي: `update_url` في manifest. ملف `../updates.json` لا يُعلن هذه النسخة حتى تجهز **نسخة موقعة**؛ إصدار 2.8.21 الحالي يحتاج تحديثًا يدويًا واحدًا للانتقال إلى أول إصدار يدعم التحديث الذاتي.

لتجهيز حزمة غير موقّعة للتوقيع، شغّل GitHub Actions: [Package unified Noor Firefox extension](../../.github/workflows/build-unified-noor-addon.yml). للحفاظ على التوقيع يجب توقيع كل تعديل عبر Mozilla قبل نشره.
